description=Extracts tree tops and individual tree crown polygons from a CHM raster using single-pass numpy algorithms.
about=CHM (Canopy Height Model) から局所最大値法で樹頂点を抽出し、Dalponte & Coomes (2016) の領域拡張または Silva et al. (2016) のボロノイ分割で単木の樹冠ポリゴンを作成します。GRASS / GDAL のアルゴリズム連鎖と中間ファイルを使わず、numpy の配列演算で完結します。numpy は QGIS に同梱されています。scipy があれば自動的に使用しますが、無くても主要機能は動作します。

changelog=0.5.0
    - 樹頂点抽出・樹冠ポリゴン生成の両方に「処理範囲 (任意)」を追加
      キャンバスの表示範囲や座標を指定すると, その範囲だけを処理する
      指定した範囲だけをタイル分割して読み込むため, 全体を読む必要が無い
    - 両方に「処理範囲ポリゴン (任意)」を追加
      樹頂点抽出: ポリゴンの内側にある樹頂点だけを残す (点群を事後フィルタ)
      樹冠ポリゴン生成: ポリゴンの外側を無立木地扱いにする
        (gdal.RasterizeLayer でブロックごとにラスタ化, 既存の立木地マスクと
        同じ仕組みに統合)
  0.4.2
    - 詳細パラメータ「樹冠内の穴を埋める」の既定を OFF に変更
  0.4.1
    - 樹冠ポリゴンの出力レイヤに既定スタイルを適用 (塗り不透明度 50%)
    - 既定値の変更: 樹冠の最大半径 5.0 -> 10.0 m、
      種の高さに対する割合 0.45 -> 0.55
      (樹木とみなす最低高 2.0 m、除去する高さの割合 0.30 は据え置き)
  0.4.0
    - 分割方式の既定をボロノイ (Silva) に変更
    - 「樹冠を樹頂点と連結した部分に限る」オプションを追加 (既定 ON)
      ボロノイが林道や無立木地のギャップを飛び越えるのを防ぐ
    - 立木地マスク (任意のラスタ) を追加。0 / NoData のセルを樹冠から除外
      セルサイズが CHM と違っても最近傍で合わせて読む。反転指定も可能
    - マスクで除外された樹頂点の件数をログに出力
  0.3.1
    - 樹冠ポリゴンが 1 件も出力されない不具合の原因究明と対策
    - 樹頂点レイヤの CRS が CHM と違う場合に座標変換するよう修正
      (従来は全点が範囲外と判定され、黙って 0 件になっていた)
    - gdal.Polygonize が 0 件を返した場合を検知し、自前実装に自動退避
      マスクバンドを Byte で作成し、駄目ならマスク無しで再試行
    - QgsGeometry.fromWkb は戻り値が無く失敗を通知できないため、
      起動時に自己診断し、駄目なら座標列から組み立てる経路に切替
    - MultiPoint の樹頂点レイヤに対応
    - 各段階の件数をログに出力 (採用/範囲外/割当セル/ポリゴン/出力)
  0.3.0
    - プラグイン名を Canopy Extractor に変更 (プロバイダ ID: canopyextractor)
    - 樹冠ポリゴン生成アルゴリズムを追加
      領域拡張 (Dalponte & Coomes 2016) とボロノイ (Silva et al. 2016)
    - 樹冠の最大半径はメートル指定 (セルサイズから自動換算)
    - 樹冠投影面積 crown_area をセル数から直接算出
    - ポリゴン化は gdal.Polygonize (MEM 経由) を主、自前の境界追跡を保険とする
  0.2.0
    - CHM 平滑化オプションを追加 (平均フィルタ / ガウシアン)
      NoData を除外する正規化畳み込みで実装
    - ガウシアンの sigma はメートル指定 (セルサイズから自動換算)
    - 樹高の取得元を選択可能に (既定は元の CHM)
    - 平滑化のカーネル半径をタイル処理の halo に加算
  0.1.1
    - GDAL の ReadAsArray をやめ ReadRaster + numpy で読むよう変更
      (osgeo.gdal_array と numpy の ABI 不一致による ImportError を回避)
    - リーダ生成時に試し読みを行い、失敗時は QGIS プロバイダ経由に自動切替
    - 使用中の計算バックエンドと NoData をログに出力
  0.1.0
    - プロトタイプ初版
    - Processing モデル 樹頂点抽出0_5_0 の numpy 1 パス実装
